# Уведомления

## Зачем они нужны

Приложение может присылать **локальные уведомления на iPhone**, когда у человека из списка **включена цикличность жизни** и настроена цепочка этапов: напоминание о том, что наступает **новый этап**.

Текст уведомления формируется из имени человека и названия следующего этапа (или человекочитаемого описания настроения этапа).

## Как включить

1. При первом запуске приложение инициализирует систему уведомлений и запрашивает разрешение у **iOS** (алерт, звук, значок — по системному диалогу).
2. Чтобы напоминания имели смысл, у нужного человека в профиле должна быть включена **«Цикличность жизни»** и заданы этапы с датой отсчёта цикла.

Перепланирование напоминаний выполняется приложением **при загрузке главного экрана и при сохранении списка с главного экрана**. Если человек с циклом был добавлен только через **«Профиль по ссылке»**, напоминания для него могут **ещё не запланироваться**, пока главный экран снова не сохранит список (часто это бывает после **полного перезапуска** приложения).

Если разрешение было отклонено, его нужно включить вручную: **Настройки iPhone → Уведомления → [приложение «Настрой» / Nastroy]** — включите нужные типы оповещений.

## Время напоминания

В текущей версии приложения время фиксировано на стороне кода: уведомление планируется **около 09:00** по **местному времени** устройства в день ожидаемой смены этапа.

**Отдельного экрана в приложении для выбора часа напоминания нет.**

## Как отключить или ослабить

- **Полностью для приложения** — отключите уведомления для приложения в системных настройках iOS.
- **Логически для человека** — выключите **«Включить цикличность жизни»** в экране **«Цикличность жизни»** этого профиля или удалите этапы так, чтобы цикл не планировался.

Когда срабатывает сохранение списка **с главного экрана**, приложение **снимает все** запланированные напоминания этого типа и создаёт заново по текущим данным — изменения в профилях переопределяют расписание после этого шага.

## Почему может не приходить

- Нет разрешения на уведомления.
- У человека выключен цикл или не заданы этапы / дата старта.
- Фокус / режим «Не беспокоить» или суммарные настройки фокусов скрывают алерты.
- Система отложила доставку точного будильника (реже на iOS для локальных уведомлений; на Android использовался бы другой режим точности — см. техническую документацию, если собираете не только iOS).

Технические подробности: `docs/technical/notifications.md`.

## Замечание про экран «Как пользоваться»

В приложении на экране **«Как пользоваться»** в разделе про будущие возможности упоминаются уведомления как часть дорожной карты. На практике **уведомления о цикле уже реализованы** — ориентируйтесь на поведение, описанное выше.
