# Начало работы

Добро пожаловать. Ниже — самый быстрый способ начать пользоваться «Настроем».

## 1) Установите и откройте приложение

1. Установите **«Настрой»** на iPhone.
2. Откройте приложение с домашнего экрана.
3. Разрешите уведомления, если хотите получать напоминания о смене этапов.

## 2) Сделайте первый полезный шаг

1. Нажмите на свой аватар в правом верхнем углу.
2. Выберите актуальный настрой для себя.
3. Вернитесь на главный экран.

Это займет меньше минуты, но сразу поможет почувствовать, как работает приложение.

## 3) Добавьте первого человека

1. Нажмите кнопку **«+»**.
2. Выберите:
   - **Создать вручную** — если заполняете профиль сами;
   - **Импорт по коду** — если вам прислали ссылку или код.
3. Откройте карточку человека и посмотрите подсказки по общению.

## Что где находится

- Вверху: название приложения и кнопка с подсказками «Как пользоваться».
- Справа вверху: ваш аватар и переключатель темы.
- Внизу справа: кнопка **«+»** для быстрых действий.

## Нужно ли подключение к интернету?

Для базовой работы — нет. Основные данные хранятся на вашем устройстве.
