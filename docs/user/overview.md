# Что такое «Настрой»

**«Настрой»** — это приложение, которое помогает лучше понимать близких и бережнее с ними общаться.

Вы добавляете людей, отмечаете их текущее состояние и сразу видите подсказки:
- что сейчас лучше сделать;
- чего лучше избежать.

## Зачем это может быть полезно

- меньше неловких ссор «на ровном месте»;
- проще поддержать человека в нужный момент;
- удобнее держать важные детали в одном месте.

## Что умеет приложение

- хранит профили людей прямо на вашем iPhone;
- показывает наглядный экран состояния каждого человека;
- позволяет делиться профилем через ссылку или QR;
- поддерживает виджет на iPhone и приложение на Apple Watch;
- умеет работать с цикличностью (когда состояние меняется по этапам).
