# Приложение на iPhone

## Главный экран

- **Заголовок «Настрой»** и иконка **i** — экран **«Как пользоваться»**.
- **Поиск по имени** появляется, когда в списке **не менее девяти** друзей (не считая «Я»). Во время активного поиска порядок карточек **не меняется** перетаскиванием — очистите поле поиска, чтобы снова упорядочивать сетку.
- **Карточки на экране** — только люди с типом списка «друзья»; профиль **«Я»** на сетке не показывается, только через аватар в шапке.
- Если друг **один**, его карточка показывается крупнее (**режим одного человека**).
- Пустой список: текст **«Пока никого нет»** и предложение добавить или импортировать профиль.

### Кнопка «+» (FAB)

Открывает два дополнительных мини-действия (когда меню развернуто):

1. **Смайлик** — кнопка **выше** основной «+»: быстрый выбор вашего настроя («Изменить мой настрой»).
2. **Человечек с плюсом** — кнопка **левее** основной «+»: меню **«Создать вручную»** / **«Импорт по коду»**.

Закрыть меню можно нажатием на фон экрана вне кнопок.

### Перетаскивание

При **двух и более друзьях** и **без активного поиска** порядок карточек меняется так же, как в подсказке на главном экране: **зажмите карточку и перетащите**. Порядок сохраняется на устройстве.

### Подсказка‑полоска над сеткой

Текст про «+» и перетаскивание показывается, если друзей **не один** (то есть **0** или **≥ 2**) и подсказку ещё не закрыли крестиком. Если друг **ровно один**, полоска не показывается.

## Профиль «Я»

Открывается нажатием на **ваш аватар** справа вверху.

- Можно менять данные как у обычного профиля (**«Редактировать»**).
- Удаление профиля «Я» с главного экрана не предлагается тем же способом, что у друзей.

## Создание человека

Экран **«Новый человек»**. Кнопка **«Сохранить»** в шапке.

Заполняются имя, пол, вариант аватара, настрой, тип отношений, подсказки «помогает» / «избегать» (в том числе свои варианты через «Другое»). Новый человек попадает в список как **локальный** профиль.

## Импорт по коду

Экран **«Импорт по коду»**.

Вставьте **ссылку или текст кода**, который вам прислали, в поле **«Ссылка или код профиля»**, нажмите **«Импортировать»**.

- Если формат не распознан — сообщение **«Ссылка или код не распознаны»**.
- Если человек с таким идентификатором уже есть — всплывающее **«Человек с таким кодом уже есть в списке»**, дубликат не добавляется.

## Профиль человека (экран карточки)

Открывается нажатием на человека в сетке.

- Вокруг персонажа — интерактивные подсказки; их можно нажимать.
- **Поделиться** — диалог **«Поделиться профилем»**: QR и кнопка **«Скопировать ссылку»** (появится **«Ссылка скопирована»**).
- **Удалить из списка** — значок корзины есть только если экран открыт с **главного экрана** для человека из списка (передаётся колбэк удаления). После открытия по **deep link** или на экране **«Профиль по ссылке»** после **«Добавить»** кнопка удаления **может не отображаться** — вернитесь на главный экран и откройте карточку оттуда, чтобы удалить человека.
- **Редактировать** — только для **локальных** профилей. Импортированные профили в приложении **не редактируются** таким способом (но их можно **удалить** из списка и при необходимости импортировать снова).

Для **«Я»** заголовок состояния может показываться как **«Мой настрой»**.

## Редактирование

Экран **«Редактировать»**, кнопки **«Сохранить»**.

Доступны те же поля, что при создании. У друзей (не «Я») в шапке есть иконка **цикла** — переход к экрану **«Цикличность жизни»** (только для локальных профилей).

## Цикличность жизни

Экран **«Цикличность жизни»**.

- Переключатель **«Включить цикличность жизни»** — когда включено, настрой берётся из последовательности этапов (подпись на экране).
- Этапы можно **добавлять**, менять и **перетаскивать** для порядка.
- **«Сохранить»** в шапке фиксирует изменения.

Дальше нужно сохранить профиль через **«Редактировать»** и вернуться на **главный экран**: тогда выполняется полное сохранение списка и обновление виджета, часов и **уведомлений** о цикле — см. [notifications.md](notifications.md).

## Профиль по ссылке

Если приложение открылось по подходящей ссылке с данными профиля, может появиться экран **«Профиль по ссылке»** с кнопкой **«Добавить»**. Если этот профиль уже был в списке, откроется его карточка в режиме просмотра.

**Важно (как устроено сейчас):** после **«Добавить»** приложение записывает человека в **локальное хранилище** на iPhone, но **не** обновляет автоматически виджет, синхронизацию с Apple Watch и расписание уведомлений — это происходит только когда отрабатывает сохранение списка **с главного экрана** (чаще всего после **полного перезапуска** приложения с последующей загрузкой главной или после действий, которые приводят к сохранению списка на главном экране). Кроме того, **список людей на главном экране** после возврата назад может **ещё не показывать** нового человека, хотя он уже записан в хранилище; при необходимости **полностью закройте приложение** и откройте снова.

Открытие ссылки **на уже сохранённого человека** через схему **`nastroi://person/…`** ведёт на профиль только если человек есть в списке — см. `docs/technical/deep-links.md`.

## Тема оформления

Кнопка с иконкой солнца или луны в шапке переключает **тёмную и светлую** тему. Выбор **не запоминается** между перезапусками приложения — при следующем запуске снова используется тёмная тема по умолчанию.
