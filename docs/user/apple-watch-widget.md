# Виджет (complication) на Apple Watch

## Что это

Это **круглый элемент complication** для циферблата Apple Watch: маленький аватар в цветном круге, отражающий текущее настроение выбранного человека (или запасное изображение / иконка, если данных нет).

В коде виджет поддерживает только семейство **круглого аксессуара** (**Accessory Circular**) — другие форматы complication этим расширением не задаются.

## Что показывает

- Изображение персонажа в соответствии с полом, вариантом аватара и настроением (при наличии ресурса с суффиксом `complication`).
- Фон — градиент по типу настроения.

Источник данных — тот же список, что получает приложение Watch с iPhone (ключ **`watch_people`** в общем хранилище на часах). Если пользователь в приложении Watch **выбрал конкретного человека для виджета**, complication показывает **его**; иначе обычно берётся **первый** из списка.

## Как добавить на циферблат

1. Долго нажмите на **текущий циферблат**.
2. Выберите **«Изменить»** и перейдите к слоту complication.
3. Найдите **«Настрой»** в списке приложений и выберите предложенный круглый виджет.

Точные названия пунктов меню зависят от версии **watchOS** и языка системы.

## Обновление

В коде расширения запрошен следующий пересчёт таймлайна примерно **через 60 секунд** — это не гарантия точного времени обновления на циферблате.

После получения новых данных с iPhone приложение Watch запрашивает обновление таймлайнов виджета; система watchOS может отложить перерисовку. При смене человека для complication приложение также запрашивает перезагрузку.

Если человек был добавлен только через **«Профиль по ссылке»** без сохранения с главного экрана телефона, список на часах может **ещё не содержать** его — см. [iphone-app.md](iphone-app.md).

Если картинка не менялась долго: откройте приложение «Настрой» на iPhone и дождитесь главного экрана, затем проверьте часы — подождите несколько минут.

## Ограничения watchOS

- Виджет **не интерактивный** как полноценное приложение: основное взаимодействие — открытие приложения или системные действия по правилам Watch.
- Частота обновлений ограничена **WidgetKit** и энергосбережением.
