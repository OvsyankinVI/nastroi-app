# Решение проблем

## После «Добавить» на экране «Профиль по ссылке»

- Новый человек может **не появиться сразу** на главном экране — **полностью закройте приложение** (смахните из переключателя задач) и откройте снова.
- Виджет на iPhone и данные на Apple Watch могут **не обновиться**, пока не выполнится сохранение списка с главного экрана — после перезапуска откройте приложение и дождитесь главного экрана.

Подробности: `docs/technical/architecture.md`.

## Виджет на iPhone пустой или показывает «Добавь друга»

1. Откройте приложение «Настрой» и убедитесь, что в списке есть **хотя бы один друг** (не только «Я»).
2. Подождите минуту и долго нажмите на виджет → **«Изменить виджет»** → выберите человека.
3. Удалите виджет с экрана и добавьте снова.

Если проблема сохраняется после переустановки приложения — возможна ошибка сборки с App Group (разработчикам: см. `docs/technical/widgets.md`).

## Уведомления не приходят

1. **Настройки → Уведомления** — разрешите для приложения.
2. У человека откройте **«Цикличность жизни»** — переключатель включён, этапы заполнены, дата старта есть смысл.
3. Помните: время фиксировано (**утро**, см. [notifications.md](notifications.md)), отдельной ручной настройки времени в приложении нет.
4. Проверьте режимы **Фокус** и **Не беспокоить**.

## Apple Watch: список пустой

- Откройте приложение на **iPhone** и дождитесь главного экрана.
- Убедитесь, что на часах установлено приложение из **того же выпуска**, что и на телефоне.
- На телефоне должны быть люди с типом **друзья** — профиль **«Я»** в этом канале на часы **не передаётся**.

Если после этого списка нет — перезапустите часы и телефон.

## Complication не меняется

- В приложении на часах выберите человека действием **«В виджет»** / **«Показать в виджете»**.
- Обновите данные на iPhone и подождите несколько минут.

См. [apple-watch-widget.md](apple-watch-widget.md).

## Приложение не открывается по ссылке

- Для открытия профиля по **`nastroi://person/…`** человек должен **уже быть** в вашем списке на этом устройстве — иначе экран просто не откроется с переходом.
- Ссылки **`https://…`** без настройки Universal Links могут открываться в браузере — используйте **«Импорт по коду»**, вставив ссылку или код целиком.

Подробности: `docs/technical/deep-links.md`.

## После импорта «Человек с таким кодом уже есть»

Это не ошибка: такой профиль уже сохранён. Откройте его с главного экрана по имени.

## Данные «сбросились» или показаны демо-люди

При повреждении сохранённого файла или первом запуске приложение может подставить **встроенный демонстрационный список**. Если вы только что удалили приложение или очистили данные — список будет как при новой установке.

## Тема постоянно тёмная после перезапуска

Так и задумано в текущей версии: переключатель темы работает **до закрытия** приложения; после запуска снова **тёмная** тема по умолчанию.
