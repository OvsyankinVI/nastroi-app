# Решение проблем

Если что-то работает не так, начните с коротких шагов ниже.

## Человек не появился после добавления по ссылке

1. Полностью закройте приложение.
2. Откройте его снова.
3. Проверьте список на главном экране.

## Виджет iPhone пустой

1. Убедитесь, что в приложении есть хотя бы один добавленный человек.
2. Зажмите виджет → **«Изменить виджет»** → выберите человека.
3. Если не помогло — удалите виджет и добавьте заново.

## Уведомления не приходят

1. Проверьте разрешение: **Настройки iPhone → Уведомления → Настрой**.
2. Проверьте, включена ли цикличность у нужного человека.
3. Проверьте режимы Фокус/«Не беспокоить».

## На Apple Watch пустой список

1. Откройте «Настрой» на iPhone.
2. Дождитесь главного экрана.
3. Откройте «Настрой» на часах снова.
4. При необходимости перезапустите часы и телефон.

## Complication на часах не обновляется

1. Выберите человека через действие **«В виджет»** в приложении на часах.
2. Откройте приложение на iPhone.
3. Подождите немного (watchOS обновляет не мгновенно).

## Ссылка не открывается как приложение

Используйте экран **«Импорт по коду»** и вставьте ссылку/код вручную.
