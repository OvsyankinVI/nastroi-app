# Виджет на iPhone

Виджет нужен, чтобы одним взглядом понять состояние человека, не открывая приложение.

## Что показывает виджет

- аватар;
- имя;
- при включенной цикличности — текущий этап.

Профиль **«Я»** в виджет не попадает — только добавленные люди.

## Как добавить

1. Зажмите экран iPhone.
2. Нажмите **«+»**.
3. Найдите виджет **«Настрой»** (или **Nastroi**).
4. Добавьте маленький виджет.

## Как выбрать человека

Зажмите виджет → **«Изменить виджет»** → выберите человека.

## Когда обновляется

Виджет обновляется автоматически, но не мгновенно — это нормально для iOS.

Если вы только что меняли данные в приложении:
1. откройте «Настрой»;
2. вернитесь на главный экран;
3. подождите немного.

## Если виджет пустой

- проверьте, что в приложении есть хотя бы один добавленный человек;
- выберите человека в настройках виджета;
- удалите виджет и добавьте заново, если нужно.
