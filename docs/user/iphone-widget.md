# Виджет на iPhone

## Что показывает

В коде расширения отображаемое имя конфигурации задано как **«Nastroi»** (на телефоне в списке виджетов может совпасть с именем приложения **«Настрой»** в зависимости от локализации и сборки). Показывается **один выбранный человек** из списка друзей:

- аватар в стиле приложения (или эмодзи, если картинка недоступна);
- **имя**;
- при включённом цикле жизни у этого человека на телефоне — строку **текущего этапа** (то, что последний раз записано для виджета при сохранении данных на iPhone).

Профиль **«Я»** в данные виджета **не передаётся** — в списке выбора только другие люди из приложения.

## Размер

В приложении поддерживается только семейство **маленького виджета** (**Small**). Изменить виджет до среднего или большого размера в коде не предусмотрено — если система предложит только малый размер, это ожидаемо.

## Как добавить виджет

1. На домашнем экране iPhone **долго нажмите** на свободное место или на виджет-пустырь.
2. Нажмите **«+»** в левом верхнем угу.
3. Найдите виджет приложения **«Nastroi»** / **«Настрой»** (название зависит от локализации и сборки).
4. Выберите размер **Small** и добавьте на экран.

## Выбор человека

При добавлении или редактировании виджета (**«Изменить виджет»**) доступен параметр **«Человек»** — список совпадает с теми профилями, которые приложение передало в общее хранилище. Если никого не выбрать, отображается первая доступная запись или заглушка (**«Добавь друга»** на стороне виджета).

## Обновление

Виджет обновляет расписание по правилам **WidgetKit** (в коде задан интервал пересборки таймлайна порядка **15 минут**, фактическое обновление может происходить реже).

После изменений списка приложение перезаписывает данные для виджета **в том числе** при первой загрузке главного экрана и когда вы сохраняете изменения, вернувшись на главный экран из профилей (создание/импорт через меню «+» и правки через карточку человека **обновляют** данные для виджета). Если человек попал в список только через **«Профиль по ссылке»** без этого шага, виджет может ещё не обновиться — откройте приложение и дождитесь главного экрана или перезапустите приложение (см. [iphone-app.md](iphone-app.md)).

## Нажатие на виджет

Тап по виджету открывает приложение по ссылке вида **`nastroi://person/…`** для выбранного человека. Профиль откроется, только если этот человек **есть в вашем локальном списке**.

## Если виджет пустой или устарел

- Откройте приложение на iPhone и вернитесь на главный экран — данные пересохраняются при загрузке и после правок.
- Убедитесь, что у приложения и расширения виджета в настройках включена общая **App Group** (делается разработчиком при сборке).
- Удалите и снова добавьте виджет.

Подробнее для разработчиков: `docs/technical/widgets.md`.
